# pymongo-api
## Схема
Схема итогового решения находится в файле task1.drawio

## Как запустить
1. Нужно перейти в директорию sharding-repl-cache
```
cd ./sharding-repl-cache/
```
2. Выполнить команду
```
docker compose up -d
```
3. Выполнить скрипт инициализации mongodb и наполнения БД данными
```
./scripts/mongo-init.sh
```
4. Проверить распределение элементов БД по шардам
```
./scripts/mongo-check.sh
```
5. Проверить доступность приложения запустив http://localhost:8080
6. Проверить реализацию кэширования запустив http://localhost:8080/helloDoc/users и замерив время выполнения несколько раз
